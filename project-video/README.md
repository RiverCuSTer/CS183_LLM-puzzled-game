# Project Videos

This folder documents the demonstration videos for the CS183 LLM puzzled game project.
The video files are not stored directly in the Git repository. Large `.mp4` files should
be uploaded separately from the repository.

## Video Assets

| Video | Description |
| --- | --- |
| `Concept.mp4` | Concept demonstration |
| `Version1.mp4` | Version 1 demonstration |
| `CS183_Version2 clip.mp4` | Version 2 demonstration |
| `CS183LLM_final.mp4` | Final project demonstration |

## Evidence

- `evidence/screenshots/`: representative screenshots or video cover images
- `evidence/diagrams/game-flow.svg`: overall game flow diagram
- `evidence/diagrams/llm-level-design.svg`: LLM learning level design diagram
- `evidence/diagrams/system-interaction-flow.svg`: system and interaction flow diagram
- `evidence/diagrams/version-comparison.png`: Version 1 and Version 2 comparison diagram
- `evidence/metrics/`: short notes, evaluation results, or video metadata

## Notes

- Do not commit large raw video files to this folder.
- Keep supporting materials small and easy to review.
